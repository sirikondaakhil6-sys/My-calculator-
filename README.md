# VIBGYOR PWA Calculator

## Features
- Basic calculator
- 7 VIBGYOR-inspired accent colors
- Dark/Bright mode
- Small, Medium, Large calculator sizes
- Settings saved automatically
- Offline PWA support
- Installable from supported browsers

## Run
For PWA installation/service worker support, host the folder using a local web server or HTTPS.
Open `index.html` for a quick preview.
